# 봉화대 사수

사방에서 몰려오는 도깨비·산적·요괴로부터 가운데 봉화대를 지키는 도트 타워 서바이벌 웹게임입니다. 라운드마다 바뀌는 상점에서 무기와 강화를 사 모아 빌드를 짜고, 40라운드를 버틴 뒤 최종 보스 흑룡을 쓰러뜨리면 이깁니다.

## 실행

빌드 과정은 없습니다. 다만 글꼴 파일을 불러오므로 `file://`로 직접 열기보다 정적 서버로 여세요.

```sh
npx http-server .   # 그다음 http://localhost:8080/
```

**바로 플레이:** https://bhdefence.github.io/ (GitHub Pages)

## 화면

가운데 밤 전장을 두고 왼쪽에는 **장터**(상점 8칸·새로고침), 오른쪽에는 **봉수대**(체력·천벌·도구)와 **봇짐**(가방)이 옻칠 나무 날개처럼 붙어 있습니다. 휴대폰을 가로로 들면 양손 엄지 아래에 하나씩 옵니다.

- 밤 조명: 전장 위에 어둠을 깔고 봉수대 불, 석등, 초롱, 초가집 창문, 화살·폭발이 빛을 뚫습니다. 적은 어둠 속에서 눈빛부터 보이며 다가옵니다.
- 다섯 홰: 봉수대는 조선 봉수처럼 연조 다섯 개를 가졌고, 체력이 20% 줄 때마다 불이 하나씩 꺼집니다.
- 손맛: 처치하면 엽전이 전대로 날아들고 먹물 자국이 남습니다. 산 물건은 봇짐 칸으로 날아가고, 세트가 완성되면 낙관 도장과 함께 알림이 뜹니다. 보스 토벌과 천벌에는 잠깐의 타격 정지가 있습니다.
- 메뉴와 창: 한지 두루마리, 붓글씨 제목(East Sea Dokdo), 명조 소제목(Song Myung), 단청 띠.
- 같은 물건을 또 사면 봇짐 한 칸에 ×2, ×3으로 겹쳐 쌓입니다. 가방 24칸은 물건 종류 수로 셉니다. 겹친 칸을 누르면 하나씩 되팔 수 있습니다.
- 휴대폰을 세로로 들고 열면 "가로 화면으로 할까요?"를 묻고, 누르면 전체 화면·가로 고정을 시도합니다. 브라우저가 막으면 화면 자체를 90° 돌려 보여 줍니다.
- 화면 폭은 창 비율에 따라 1280~1600으로 바뀌어, 넓은 휴대폰에서는 검은 여백 대신 양쪽 날개가 넓어집니다.

## 게임 구성

| 요소 | 내용 |
| --- | --- |
| 라운드 | 라운드마다 30초, 모두 40라운드. 10·20·30라운드에 두억시니·불가사리·구미호, 40라운드 뒤 최종 보스 흑룡(체력 20%마다 비늘 갑옷이 바뀜) |
| 상점 | 8칸, 라운드마다 바뀜. 라운드마다 무료 새로고침 1회, 그다음은 값이 오름. 가방은 24칸이고 되팔 수 있음 |
| 상성 | 창검→중갑, 궁시→경갑, 부적→철갑, 화포→석갑에 2배. 요술은 상성 없이 0.5~2배 무작위 |
| 세트 | 서로 다른 같은 종류 무기 2·4·6종(요술만 2·3·5종)(피해 +15/35/70%와 종류별 특수 효과), 같은 속성(화염·냉기·독·뇌전) 2·4개 |
| 이벤트 | 5·15·25·35라운드의 보물 도깨비를 잡으면 선물 셋 가운데 하나를 고름. 천벌(Z)은 한 판에 한 번 화면의 적을 쓸어냄 |
| 난이도 | 쉬움·보통·어려움, 그리고 앞 단계를 이기면 열리는 악몽 I~III |
| 수호 기억 | 판을 마칠 때 버틴 라운드만큼 기억 조각을 받아 영구 능력(시작 엽전, 수입, 체력, 무료 새로고침, 희귀 확률 등)을 배움 |
| 주간 랭킹전 | 보통 난이도, 한 주 동안 모두에게 같은 상점·같은 적 순서. 하루 3번 도전 |

조작: `1`~`8` 구매 · `R` 새로고침 · `Z` 천벌 · `B` 세트 · `D` 딜미터 · `G` 사거리 · `H` 상성표 · `Tab` 배속 · `Space` 멈춤 · `M` 배경음악. 휴대폰은 가로 화면에서 상점 칸을 두 번 눌러 삽니다.

## 업데이트할 때

`index.html`의 `<script src="…js?v=…">` 버전 값을 올리면 방문자 브라우저가 옛 파일 대신 새 파일을 받습니다.

## 공개 페이지

- `about.html` 게임 소개, `privacy.html` 개인정보처리방침, `robots.txt`·`sitemap.xml` 검색 등록용, `og.png` 링크 미리보기 그림, `favicon.png`·`apple-touch-icon.png`·`icon-512.png` 아이콘

## 파일

- `index.html`: 화면 구성과 스타일
- `data.js`: 무기·강화·적·난이도·수호 기억 데이터
- `art.js`: 도트 스프라이트, 아이콘, 전장 그리기
- `game.js`: 게임 진행, 전투, 상점, 메뉴, 저장
- `fonts/`: Galmuri11 글꼴(수정하지 않은 원본)과 SIL OFL 1.1 라이선스

## 계정·저장·랭킹

- **게스트:** 로그인 없이 바로 플레이합니다. 진행은 이 브라우저(`localStorage`)에만 저장됩니다.
- **로그인:** 영문 아이디(영문 소문자로 시작, 소문자·숫자·`_`, 4~16자)와 비밀번호(8~64자, 한글 불가)로 가입합니다. 이메일은 받지 않습니다. 가입할 때 한 번만 보여 주는 **복구코드**로 비밀번호를 재설정할 수 있고, 복구코드를 5번 틀리면 30분 잠깁니다.
- 로그인하면 진행이 서버에 자동 저장되어 다른 기기에서도 이어집니다. **주간 랭킹전**은 로그인해야 참가하고, 기록은 아이디로 **명예의 전당**에 자동으로 올라갑니다(한 사람당 이번 주 최고 기록 하나).
- 서버: `api/` 의 Cloudflare Worker(`bonghwa-api`)와 D1 데이터베이스 `bonghwa`(스키마 `api/schema.sql`). 비밀번호와 복구코드는 PBKDF2로 해시해 저장합니다.
- 배포: `main`에 `api/` 변경이 올라오면 `.github/workflows/deploy-api.yml`이 배포합니다. 저장소 Secrets에 `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`가 있어야 합니다.
- claude.ai 아티팩트로 열면 계정 대신 claude.ai 로그인과 아티팩트 저장소를 씁니다.
